# Jump Ads — мини-CRM заявок

Клиент пишет Telegram-боту, бот собирает заявку (имя, контакт, запрос) и при нехватке данных задаёт до 2 вопросов про бизнес и бюджет. ИИ оценивает заявку и ставит теги, заявка появляется в CRM.

- **CRM:** https://jump-ads-crm.vercel.app
- **Бот:** https://t.me/Jump_Ads_bot

Стек: Next.js (сайт + API вебхука) на Vercel, Postgres в Neon, Anthropic API (`claude-haiku-4-5-20251001`, ответ в JSON по схеме).

## Где что лежит

| Что | Файл |
|---|---|
| Критерии оценки | `lib/criteria.ts` |
| Запрос к ИИ | `lib/ai.ts` |
| Логика бота | `lib/bot.ts` |
| Вебхук Telegram | `app/api/telegram/route.ts` |
| Страница CRM | `app/Crm.tsx` |
| Схема БД и демо-данные | `db/schema.sql`, `db/seed.mjs` |

## Переменные окружения

Скопируйте `.env.example` в `.env.local` и заполните:

```
TELEGRAM_BOT_TOKEN=       # токен от @BotFather
TELEGRAM_WEBHOOK_SECRET=  # любая случайная строка, Telegram пришлёт её в заголовке
ANTHROPIC_API_KEY=
DATABASE_URL=             # строка подключения Neon
```

## Локальный запуск

```bash
npm install
npm run db:setup   # таблицы + 10 демо-заявок (если база пустая)
npm run dev        # http://localhost:3000
```

Проверить бота локально без деплоя (только пока вебхук не установлен):

```bash
npm run bot:poll   # забирает сообщения бота и пересылает их в локальный /api/telegram
```

## Деплой на Vercel

```bash
npx vercel link
npx vercel env add TELEGRAM_BOT_TOKEN production   # и так же для остальных трёх переменных
npx vercel deploy --prod
```

Функции работают в регионе `fra1` (`vercel.json`) — рядом с базой Neon во Франкфурте.

## Вебхук

После деплоя:

```bash
npm run webhook:set -- https://jump-ads-crm.vercel.app
```

Скрипт вызывает `setWebhook` с адресом `/api/telegram`, секретом из `TELEGRAM_WEBHOOK_SECRET` и `allowed_updates: ["message"]`. Вебхук отклоняет запросы без правильного секрета (403) и игнорирует повторную доставку одного и того же апдейта.

Проверить: `https://api.telegram.org/bot<TOKEN>/getWebhookInfo`.

## Личный Telegram

Не подключается: пункт 2 сознательно не делали — бот получил бы доступ ко всей личке владельца. Для агентства это решается подключением бота к рабочему аккаунту менеджера через Secretary Mode.

## Как проверить

1. Пишу боту «нужна реклама для стоматологии». Бот спрашивает про бюджет, через несколько секунд заявка в таблице с тегами «клиника» и «подходит».
2. Пишу «тест». Бот задаёт уточняющий вопрос, заявка с оценкой «уточнить».
3. Нажимаю «Добавить заявку» в CRM. Через несколько секунд у заявки появляются ниша, оценка и теги.
4. Ставлю тег руками в карточке заявки. Фильтр «Теги» по нему её показывает.
